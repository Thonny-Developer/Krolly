# Krolly

Маленький статический сайт с одной шуткой: при открытии страницы сразу запускается рикролл на весь экран.

Для кого: для друзей, которых хочется весело разыграть.

## Что внутри

- `index.html` страница с видео и кнопкой звука
- `style.css` видео на весь экран, кнопка в углу
- `script.js` включает звук по клику

## Технологии

HTML, CSS и немного JavaScript. Сервера и базы данных нет, поэтому сайт работает на GitHub Pages.

## Запуск локально

Скачай репозиторий и открой `index.html` в браузере.

## Ограничения

Видео подгружается с YouTube через официальный плеер, нужен интернет. Без клика оно играет без звука, это правило браузеров.
