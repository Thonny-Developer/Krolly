# Krolly

Маленький статический сайт с сюрпризом. Человек нажимает кнопку «Открыть сюрприз» и получает рикролл.

Для кого: для друзей, которых хочется весело разыграть.

## Что внутри

- `index.html` главная страница
- `style.css` оформление, нормально выглядит на телефоне
- `script.js` показывает сюрприз после нажатия на кнопку

## Технологии

HTML, CSS и немного JavaScript. Сервера и базы данных нет, поэтому сайт работает на GitHub Pages.

## Запуск локально

Скачай репозиторий и открой `index.html` в браузере.

## Ограничения

Видео подгружается с YouTube, значит нужен интернет.
