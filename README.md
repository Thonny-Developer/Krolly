# Krolly

Маленький статический сайт с сюрпризом. Рикролл запускается сразу при открытии страницы, а кнопка «Включить звук» нужна потому, что браузеры не дают играть звуку без клика.

Для кого: для друзей, которых хочется весело разыграть.

## Что внутри

- `index.html` главная страница
- `style.css` оформление, нормально выглядит на телефоне
- `script.js` считает заходы в localStorage и включает звук по кнопке

## Технологии

HTML, CSS и немного JavaScript. Сервера и базы данных нет, поэтому сайт работает на GitHub Pages.

## Запуск локально

Скачай репозиторий и открой `index.html` в браузере.

## Ограничения

Видео подгружается с YouTube через официальный плеер, значит нужен интернет. Без клика видео играет без звука, это правило браузеров.
